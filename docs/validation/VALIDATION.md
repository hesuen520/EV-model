# Validation results

Generated by `sportspred report validation` from the validation runs recorded in the store. Every number comes from a run that was actually executed; nothing is typed in by hand.

Protocol for every league and market: chronological walk-forward folds; calibration fitted on a block between training and test; model selection on pooled development-fold log loss with a one-standard-error preference for the simpler candidate; the final test period read once, after selection; intervals from a bootstrap that resamples whole slates. Accuracy, calibration and price-dependent value are separate questions - nothing here says a model beats a market.
